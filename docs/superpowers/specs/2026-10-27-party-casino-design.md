# คาสิโนเถื่อน (Party Casino Web App) — Design Specification

## 1. Intent & Why
สร้างเว็บแอปพลิเคชัน **"คาสิโนเถื่อน"** สำหรับเล่นเกมไพ่ในวงเหล้ากับเพื่อน โดยผู้เล่นแต่ละคนใช้สมาร์ทโฟนของตัวเองสแกนหรือกรอกรหัสเข้าห้องเดียวกัน ใช้กระเป๋าชิปร่วมกันข้ามเกมได้ในห้องเดียว และเปลี่ยนจากการพนันเงินจริงเป็นการเดิมพันด้วย **"บทลงโทษในวงเหล้า"** เมื่อผู้เล่นคนใดคนหนึ่งชิปหมดเกลี้ยง (ล้มละลาย)

## 2. Goals, Non-Goals & Anti-Goals
### Goals
- รองรับการเล่นหลายคนผ่านมือถือของแต่ละคนแบบ Real-time (Multiplayer Room)
- ระบบ **Admin ห้อง** ที่เป็นคนเดียวที่สามารถเสกชิปเพิ่ม (Mint/Grant Chips) ให้ผู้เล่นได้
- ระบบ **กระเป๋าชิปกลางประจำห้อง** ที่คงอยู่แม้เปลี่ยนเกมไปมา (ป๊อกเด้ง ↔ แบล็คแจ็ค ↔ โป๊กเกอร์)
- ระบบ **เจ้ามือ (Dealer Mode)** สำหรับป๊อกเด้งและแบล็คแจ็ค ที่เลือกได้ว่าจะใช้ **บอทเจ้ามือกลาง (Auto Dealer)** หรือ **ผู้เล่นอาสาเป็นเจ้ามือ** (บังคับเลือกจำนวนตา เช่น 3, 5, 10 ตา)
- ระบบ **บังคับจบการเป็นเจ้ามือทันที** หากเจ้ามือที่เป็นผู้เล่นชิปหมดกลางคัน เพื่อให้รับบทลงโทษก่อน
- ระบบ **บทลงโทษเมื่อชิปหมด (Bankruptcy Punishment)** ที่มีโหมดให้เลือก 2 แบบในห้อง:
  1. **โหมดปากเปล่า (Verbal Alert Mode):** หน้าจอทุกคนขึ้นประกาศแจ้งเตือนขนาดใหญ่ว่าใครล้มละลายและต้องโดนลงโทษตามที่ตกลงกันข้างนอก
  2. **โหมดสุ่มบทลงโทษ (Wheel/Card Draw Mode):** ผู้เล่น/Admin พิมพ์รายการบทลงโทษใส่ไว้ในห้อง เมื่อมีคนชิปเหลือ 0 ระบบจะเด้งหน้าจอสุ่มเปิดการ์ด/หมุนวงล้อบทลงโทษให้เห็นพร้อมกันทั้งวง

### Non-Goals
- ไม่มีการใช้เงินจริงหรือผูกระบบชำระเงินใดๆ
- ไม่ต้องสมัครสมาชิกด้วยอีเมล/รหัสผ่าน (ใช้แค่ชื่อเล่น + Token ประจำเครื่องใน `localStorage` เพื่อกันหลุด)
- ไม่ทำโหมดจับคู่สาธารณะกับคนแปลกหน้า (เล่นเฉพาะคนที่มีรหัสห้อง 4 หลัก หรือลิงก์ห้องเท่านั้น)

### Anti-Goals
- **ห้ามซับซ้อนจนคนเมาเล่นไม่เป็น:** ปุ่มกดต้องใหญ่ ชัดเจน สีสันสไตล์นีออนคาสิโนมืด (Dark Casino Neon) อ่านง่ายแม้ในที่แสงน้อยของวงเหล้า
- **ห้ามหลุดแล้วชิปหาย:** ถ้าผู้เล่นเผลอล็อกจอมือถือหรือรีเฟรชหน้าเว็บ เมื่อเปิดกลับมาต้องกลับเข้าที่นั่งเดิมพร้อมชิปและไพ่ในมือชุดเดิมทันที

## 3. Constraints
- พัฒนาในแยกสาขา (Git Worktree) ที่ `D:\web\.worktrees\casino-party` (branch `casino-party`)
- ไม่กระทบโค้ดเดิมของโปรเจกต์ `Solid Screen & Text Display` หากต้องการเก็บไว้ หรือแยกโครงสร้างชัดเจนในโปรเจกต์ Node.js
- ทำงานได้ลื่นไหลบนเบราว์เซอร์มือถือ (iOS Safari, Android Chrome) แนวตั้ง (Portrait-first)

## 4. Approaches Considered
1. **Node.js + Express + Socket.IO Server (Selected)**
   - *การทำงาน:* เซิร์ฟเวอร์ Node.js เก็บสถานะห้อง, ชิป, สำรับไพ่ (Deck), และรอบการเล่นทั้งหมดในหน่วยความจำ ส่งเฉพาะไพ่ในมือของใครของมันผ่าน WebSocket (Socket.IO)
   - *ข้อดี:* เสถียรที่สุด รองรับ Reconnection เมื่อหน้าจอมือถือดับ ป้องกันการแอบดูไพ่คนอื่น และซิงก์หน้าจอบทลงโทษพร้อมกันทุกเครื่องได้แม่นยำ
   - *ข้อเสีย:* ต้องรันโปรเซส Node.js (`npm start`)
2. **PeerJS / WebRTC (Serverless P2P)**
   - *ข้อดี:* โฮสต์บน Static Hosting ได้
   - *ข้อเสีย:* ถ้ามือถือ Admin จอดับ ห้องพังทันที ไม่เหมาะกับวงเหล้า
3. **Firebase / Supabase Realtime**
   - *ข้อดี:* ไม่ต้องรันเซิร์ฟเวอร์เอง
   - *ข้อเสีย:* ต้องผูกบัญชี Cloud และตั้งค่า API Keys ก่อนใช้งาน

**เหตุผลที่เลือกแนวทางที่ 1:** ผู้ใช้เลือกแนวทางที่ 1 เพราะตอบโจทย์การใช้งานจริงในวงเหล้าที่หน้าจอมือถือดับบ่อยและต้องการความเสถียรของสถานะชิปและไพ่

## 5. Detailed System Design (User Decisions + Builder Defaults)

### 5.1 Room, Player Management & Admin Panel
- **การสร้างห้อง:** ผู้สร้างห้องคนแรกจะได้รับสิทธิ์ `isAdmin: true` ทันที พร้อมรหัสห้อง 4 หลัก (ตัวเลข `1000-9999` เพื่อกดง่ายบนมือถือ — *Builder's call*)
- **การเข้าห้อง & Reconnection:**
  - ผู้เล่นกรอกชื่อเล่น + รหัสห้อง 4 หลัก (หรือสแกน QR Code / กดลิงก์ที่มี `?room=XXXX`)
  - ระบบสร้าง `playerId` เก็บไว้ใน `localStorage` ของเบราว์เซอร์ เมื่อรีเฟรชหรือเน็ตหลุดแล้วต่อใหม่ เซิร์ฟเวอร์จะผูก Socket ใหม่เข้ากับ `playerId` เดิมทันที
- **Admin Panel (แผงควบคุมเฉพาะ Admin เท่านั้น):**
  - **เสกชิป (Mint/Grant Chips):** เลือกชื่อผู้เล่น (หรือตัวเอง/ทุกคน) แล้วกดเพิ่มชิปตามจำนวนที่ต้องการ (`+100`, `+500`, `+1000`, หรือระบุตัวเลขเอง) รวมถึงปุ่มชุบชีวิตคนชิปหมด
  - **สลับเกมในห้อง:** เปลี่ยนเกมระหว่าง `ป๊อกเด้ง`, `แบล็คแจ็ค`, และ `โป๊กเกอร์` (ทำได้เมื่อจบตา)
  - **ตั้งค่าอัตราจ่ายและค่าเดิมพันของแต่ละเกม (Custom Payouts & Blinds — Admin Only):**
    - **ป๊อกเด้ง:** ปรับตัวคูณการจ่ายได้เอง เช่น ชนะปกติ (ค่าเริ่มต้น `1x`), 2 เด้ง (`2x`), 3 เด้ง (`3x`), เรียง (`3x`), เซียน (`3x`), ตอง (`5x`)
    - **แบล็คแจ็ค:** ปรับตัวคูณชนะปกติ (ค่าเริ่มต้น `1x`) และตัวคูณเมื่อได้ Blackjack 21 ใน 2 ใบแรก (ค่าเริ่มต้น `1.5x` หรือจะปรับเป็น `2x` ก็ได้)
    - **โป๊กเกอร์:** ปรับค่าบังคับลงกองกลาง `Small Blind` / `Big Blind` (ค่าเริ่มต้น `10` / `20` ชิป)
  - **ตั้งค่าโหมดบทลงโทษ:** สลับโหมดระหว่าง *ประกาศแจ้งเตือนปากเปล่า (Verbal Alert)* กับ *สุ่มวงล้อ/เปิดการ์ด (Random Draw)* และแก้ไขรายการบทลงโทษในห้อง

### 5.2 Dealer System (สำหรับป๊อกเด้ง & แบล็คแจ็ค)
- ก่อนเริ่มรอบ (หรือเมื่อตำแหน่งเจ้ามือว่าง) ห้องสามารถเลือกโหมดเจ้ามือได้ 2 แบบ:
  1. **เจ้ามือระบบ (Auto Bot Dealer):** ระบบเป็นเจ้ามือกลาง มีชิปไม่จำกัด กินและจ่ายชิปให้ผู้เล่นตามกติกา
  2. **ผู้เล่นเป็นเจ้ามือ (Player Dealer):** ผู้เล่นคนใดก็ได้ที่มีชิปมากกว่า 0 กดปุ่ม **"รับเป็นเจ้ามือ"** โดย **บังคับเลือกจำนวนตา** ก่อนยืนยัน (ตัวเลือก: `3 ตา`, `5 ตา`, `10 ตา` — *Builder's call*)
- **การนับจำนวนตา & การจ่ายชิปของเจ้ามือผู้เล่น:**
  - ทุกจบ 1 ตา ระบบลดจำนวนตาที่เหลือลง 1 (`dealerRoundsLeft--`) เมื่อครบ 0 ตา ตำแหน่งเจ้ามือจะว่างลงเพื่อให้คนอื่นรับต่อหรือสลับเป็น Auto Dealer
  - เจ้ามือผู้เล่นจะได้ชิปจากคนที่แพ้ และเสียชิปตัวเองจ่ายให้คนที่ชนะ
  - **กรณีชิปเจ้ามือไม่พอจ่ายรอบนั้น (All-in/Bankruptcy Cap):** หากเจ้ามือเสียชิปจนเหลือ `0` ระบบจะจ่ายชิปเท่าที่เจ้ามือมีให้ผู้ชนะตามสัดส่วน (หรือตามลำดับ) แล้วปรับชิปเจ้ามือเป็น `0` ทันที
  - **บังคับจบการเป็นเจ้ามือเมื่อชิปหมด:** ทันทีที่จบตาแล้วชิปของเจ้ามือเหลือ `0` ระบบจะปลดผู้เล่นคนนั้นออกจากตำแหน่งเจ้ามือทันที (แม้จำนวนตาที่เลือกไว้จะยังไม่ครบ) และส่งเข้าสู่ขั้นตอนรับบทลงโทษล้มละลายทันที

### 5.3 Bankruptcy & Punishment System (ระบบบทลงโทษเมื่อชิปหมด)
- **เงื่อนไขการทำงาน:** เมื่อจบตาในเกมใดก็ตาม ผู้เล่นทุกคนที่ชิปเหลือ `0` (รวมถึงเจ้ามือที่เพิ่งเจ๊ง) จะติดสถานะ `BANKRUPT`
- **โหมดบทลงโทษ (เลือกสลับได้ในตั้งค่าห้อง):**
  1. **โหมดประกาศแจ้งเตือน (Verbal Alert Mode):** เด้งหน้าจอสีแดงฉุกเฉินพร้อมเสียงเอฟเฟกต์บนมือถือทุกเครื่องในห้อง ระบุชื่อคนชิปหมด เช่น *"🚨 [ชื่อเพื่อน] ถังแตก ชิปหมดเกลี้ยง! รับบทลงโทษตามที่ตกลงกันเดี๋ยวนี้!"*
  2. **โหมดสุ่มบทลงโทษ (Random Wheel / Card Draw Mode):**
     - มีรายการบทลงโทษในห้อง (มีค่าเริ่มต้นสายปาร์ตี้ให้ เช่น *"ดื่มเพียว 1 ช็อต"*, *"ดื่มหมดแก้ว"*, *"คนทางซ้ายสั่งดื่มอะไรก็ได้"*, *"ห้ามพูดคำหยาบ 3 ตา พูดโดนดื่ม"* และผู้เล่น/Admin พิมพ์เพิ่มหรือลบรายการเองได้ — *Builder's call*)
     - เมื่อมีคนชิปหมด หน้าจอจะแสดงการ์ด/วงล้อบทลงโทษให้ผู้เล่นที่ถังแตก (หรือ Admin) กดปุ่ม **"สุ่มบทลงโทษ!"** แล้วแสดงผลลัพธ์พร้อมกันทุกเครื่อง
- **การชุบชีวิต (Revive):** ผู้เล่นที่ชิปเหลือ `0` จะไม่สามารถลงเดิมพันในตาถัดไปได้ จนกว่าจะรับบทลงโทษเสร็จ แล้ว `Admin` กดปุ่ม **"เสกชิปชุบชีวิต"** ให้

### 5.4 Games Included in the Hub (3 เกมหลักในเว็บเดียว)
Admin สามารถกดสลับเกมในห้องได้เมื่อจบแต่ละตา โดยชิปของผู้เล่นทุกคนจะตามไปทุกเกม:

#### เกมที่ 1: ป๊อกเด้ง (Pok Deng)
- **การลงเดิมพัน:** ลูกขาทุกคนที่มีชิป > 0 เลือกจำนวนชิปเดิมพัน (ไม่เกินชิปที่ตัวเองมี)
- **การแจกไพ่:** แจกไพ่คนละ 2 ใบ (คว่ำให้เห็นเฉพาะเจ้าของมือ)
- **การตัดสินป๊อก:** ถ้าใครได้แต้มรวม 8 หรือ 9 ใน 2 ใบแรก (ป๊อก 8 / ป๊อก 9) ระบบหงายไพ่ป๊อกทันที หากเจ้ามือป๊อกจะวัดผลทันทีโดยลูกขาที่ไม่ได้ป๊อกไม่มีสิทธิ์จั่ว
- **การจั่วไพ่ใบที่ 3:** ลูกขาที่ไม่ได้ป๊อกเลือกได้ว่าจะ **"จั่ว (Draw)"** หรือ **"อยู่ (Stand)"** (บังคับจั่วถ้าแต้มน้อยกว่า 4 — *Builder's call*) จากนั้นถึงตาเจ้ามือเลือกจั่วหรืออยู่ (กรณี Auto Dealer: จั่วอัตโนมัติถ้าน้อยกว่า 5 แต้ม)
- **อัตราจ่าย (เด้ง — ปรับแต่งได้ใน Admin Panel):**
  - แต้มปกติชนะ จ่ายตามค่าที่ Admin ตั้งไว้ (ค่าเริ่มต้น `1x`, เสมอกันคืนทุน)
  - 2 เด้ง (2 ใบดอกเดียวกัน หรือเลขคู่) จ่ายตามค่าที่ Admin ตั้งไว้ (ค่าเริ่มต้น `2x`)
  - 3 เด้ง (3 ใบดอกเดียวกัน), เรียง, เซียน (J, Q, K ล้วน 3 ใบ), ตอง (3 ใบเลขเดียวกัน) จ่ายตามค่าที่ Admin ตั้งไว้ใน Admin Panel (ค่าเริ่มต้น: 3 เด้ง/เรียง/เซียน = `3x`, ตอง = `5x`)

#### เกมที่ 2: แบล็คแจ็ค (Blackjack 21)
- **การลงเดิมพัน:** ลูกขาลงชิปเดิมพัน
- **การแจกไพ่:** แจกผู้เล่นคนละ 2 ใบหงาย และแจกเจ้ามือ 2 ใบ (หงาย 1 ใบ คว่ำ 1 ใบ)
- **การนับแต้ม:** A นับเป็น 1 หรือ 11, J/Q/K นับเป็น 10
- **แอคชันของผู้เล่น:** ผลัดกันเลือกตามคิว: **"จั่ว (Hit)"**, **"อยู่ (Stand)"**, หรือ **"ลงสองเท่า (Double Down)"** (กรณีมีชิปพอและเป็น 2 ใบแรก) หากแต้มเกิน 21 จะทะลุ (`Bust`) ทันที
- **แอคชันของเจ้ามือ:**
  - ถ้าเป็น *Auto Dealer*: หงายใบคว่ำและจั่วอัตโนมัติจนกว่าจะได้แต้มอย่างน้อย 17
  - ถ้าเป็น *Player Dealer*: หงายใบคว่ำและกดเลือก Hit หรือ Stand เองได้
- **อัตราจ่าย (ปรับแต่งได้ใน Admin Panel):** ชนะปกติได้ตามค่าที่ Admin ตั้งไว้ (ค่าเริ่มต้น `1x`), ได้ Blackjack (A + 10/J/Q/K ใน 2 ใบแรก) ได้ตามค่าที่ Admin ตั้งไว้ (ค่าเริ่มต้น `1.5x` ปัดเศษขึ้นเป็นจำนวนเต็ม)

#### เกมที่ 3: โป๊กเกอร์ (Texas Hold'em Poker)
- **ไม่ต้องเลือกเจ้ามือแยก:** ใช้ระบบปุ่ม Dealer Button วนตามเข็มนาฬิกาอัตโนมัติ พร้อม Small Blind / Big Blind ที่ Admin ปรับขนาดได้ใน Admin Panel (ค่าเริ่มต้น `10 / 20` ชิป)
- **ขั้นตอนการเล่น:**
  1. แจกไพ่ในมือคนละ 2 ใบ (Hole Cards)
  2. รอบเดิมพัน **Pre-Flop** → เปิดไพ่กองกลาง 3 ใบ (**Flop**) → รอบเดิมพัน → เปิดใบที่ 4 (**Turn**) → รอบเดิมพัน → เปิดใบที่ 5 (**River**) → รอบเดิมพันสุดท้าย → **Showdown**
- **แอคชันในแต่ละรอบ:** **หมอบ (Fold)**, **ผ่าน (Check)**, **ตาม (Call)**, **เกทับ (Raise)**, และ **เทหน้าตัก (All-in)**
- **การตัดสิน (Hand Evaluator):** เปรียบเทียบไพ่ดีที่สุด 5 ใบจาก 7 ใบ (Royal Flush ลงมาถึง High Card) ผู้ชนะได้ชิปกองกลาง (Pot) ไปครอง (รองรับการแบ่ง Pot กรณีเสมอกัน หรือ Side Pot พื้นฐานเมื่อมีคน All-in)
